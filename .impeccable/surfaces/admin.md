# Publishing editor

Mode: Operate. Extend the established site; the user specifically chose BlockNote.

## Direction contract

THESIS: Make writing and deliberate publication straightforward, with drafts and
live content visibly distinct. Do not turn the site into a generic dashboard.

OWN-WORLD: Inherit the black-and-white palette and square controls. Keep the
working editor legible on a plain writing surface, without glitter behind text.

STORY: Sign in, choose or create an entry, write and upload, then save privately
or publish directly. Preview is an optional view, never a publishing prerequisite.

FIRST VIEWPORT: A compact header contains the site link and sign-out. An entry
list sits beside the writing surface; the title, save state, and publishing
controls are visible above BlockNote. One primary Publish/Update action saves the
latest draft first; Save draft remains private and secondary. Write/Preview view
controls are separate from publishing, with clear unsaved/draft/live status.
Unpublish stays in secondary controls. On mobile the list precedes the editor.

FORM: User-pinned familiar BlockNote editing surface within the incumbent world;
no replacement visual-world exercise. Seed: none (user-pinned).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish
review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
